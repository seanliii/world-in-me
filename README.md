# 世界照见我

从旅行的具体观察出发，连接全球历史、思想原典、自我认识与可检验的行动。

这是持续修订的中文研究作品，不是已完成的世界百科，也不是人格诊断或“读完就改变人生”的保证。**材料覆盖与问题回答程度分别公开，不以引用数量代替深度。**

## 阅读入口

- **旅程**：原计划二十站与旧稿提及的美洲八国，地点、现代照片和历史事件分别标明。
- **主题**：文明叙事、帝国与殖民、货币、内亚与宗教、身份边界、文学、劳动、自由、意识、研究方法与自我认识。
- **问题**：旧稿六十六问与本轮新问题。每条保留已有解释、引用及仍待回答的部分。
- **原典**：区分出版信息、公开片段和实际读取范围；已核短引附原文、自译和语境，不伪装通读。
- **讲座与播客**：在原典页可直接跳入。播客保留官方文字稿短引、中文对读、主持人的追问、独立异议与可选练习；读过文字稿不等于听校过全片。
- **行动**：只存当前浏览器的收藏、笔记、阅读和实验记录，可导出、合并导入 JSON。
- **自己**：主动导入本地私人研究包，在当前标签页内阅读；不上传、不自动保存，刷新后清除。
- **出处与纠错**：材料读取状态、逐问语义回查、来源实际入口、旧稿修订与图像许可。

## 2026-10-06 继续研究

- 原十一国现在十国有出版方／原刊／平台提供的作品片段；贝宁另有署名教学转载，Stock底本未校。新读突尼斯阿语样章文件页1—11、黎巴嫩法译标号1—3与英语期刊首图，都不等于通读。埃塞俄比亚单列，不填原十一国缺额；《利雅得女孩》的作者说明与译者异议仍并列。
- 东西罗马问题补入共治前史、驻意大利帝廷与流亡帝位的区别；用荷马与维吉尔的指定原文解释故事怎样被改写，不把神话祖谱当作可证血缘。
- 马克思、格雷伯／UBI、福柯、深层生态学四路分别比较。作者主张、就业实验、问卷与财政模拟分开，结论注明价值前提和适用条件。
- 原典页直接显示所读版本、译者与范围；旧说法的更正同步到主题、问题、书目和路线说明。私人综合稿仍只在本地导入，不随公共网站发布。
- 墨西哥1519—1521年的联盟、后勤与败退反转进入具体过程；荷兰金融另有从出票到结算的完整教学例子，不以国家性格或单一发明解释兴衰。
- 学习叙事问题新增两份历史课标、教材编写说明和学校课案的有限对照，不冒充教材正本或个人记忆原因。
- “为何选择希腊而非埃及”现补入洪堡手稿及同期边批、黑格尔同一文本的直接比较、卢浮宫馆史。1793写作、1807片段利用与1896初刊分开；哲学家的文明等级是研究对象，不是本站结论。已有中国传播段落保留，不以它替埃及部分作答。
- 法国非洲专题列十五个地区或制度分支，重点补摩洛哥、突尼斯和法属赤道非洲；独立、帝国间转手、国内行政整合与主权争议分别处理。埃及短期远征、费赞军管等仍待补，“全貌”问题继续保留部分状态。
- 宗教权威比较加入斯里兰卡受戒谱系、寺产程序与泰国历史僧团法。经典、法条、机构办事说明和学者观察分开，旧法不冒充2026现行指南。
- 原创业应用子问新增知识、授权、验证和成本的对读，以及六行协作约定、每周可选回顾和停止条件。虚构AI场景未运行，步骤和时间都是待检验建议；低风险试行不替代原任务全部成果与完整验收，也不让参与者承担未同意的额外劳动。
- 非洲发展问题以科特迪瓦和毛里求斯比较具体政策、分期结果及劳动与照护代价；同版历史数据与旧论文序列不混接，平均产出不替代家庭生活。
- 西班牙“后来失败”补入17—18世纪收缩、恢复、地区差异与相对落后，经济与失地分栏；19世纪和1898年等更晚问题仍未全部展开。
- 土耳其改革后的变化接上1950—2013年选举、国家宗教管理、学制与两起具体权利争议；不同意见不是判决结果，历史规则不冒充今日现行法。
- 波黑身份问题加入日常交往、图书馆保存、1993年集体采名与2013年原始交叉统计。民族、宗教、国籍与母语分开，人口表不是血统或内心信仰检测。

## 必须保留的边界

1. Kimi 三卷是对旧对话的二次整理，不等于原始聊天。Gmail 六封补充邮件的状态以网站逐封登记为准；没有正文就不冒称已读。
2. 原路线是规划，不是到访证明。美洲国家点是地理示意，不是用户去过的城市。
3. 小说不是国民性抽样；一次见闻不是自然实验；任何民族或宗教都不被压成一种固定性格。
4. 关于意识的研究不构成自行用药指导或医疗建议；关于个人的解释不构成诊断、天赋排名或确定未来。
5. 原始邮件、公司项目日志、内部地址和具体私人评估**不在本公开仓库**。网站隐藏入口或 noindex 不构成访问保护。

## 私人数据

阅读笔记与收藏存入当前网址的浏览器本地存储。不同设备和网址之间不自动同步；清理浏览器数据或隐私模式可能使记录丢失，请定期导出。

私人研究包是用户主动选择的本地 JSON 文件。页面只把它作为文字读取，不请求文件中的链接，不把内容放入本地存储。私人报告区使用电脑自带字体，避免报告中的新字符触发外部字库请求。候选计划之前先展示本人选择的问题，不把工作当作默认人生目标。该文件本身**未加密**，请不要将它放入公开仓库或随意分享。

外部字体、资料照片与视频按浏览器正常规则联网，相关服务可能接收正常网络请求信息，但不会附带你的私人笔记或研究包。视频须主动加载，不自动播放；展开播客中文对读不会请求外部音频，原音频和全文由用户主动打开官方原站。外部字体失效不阻挡正文。
